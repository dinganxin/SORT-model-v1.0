# SORT v1.0

SORT (Soil Optical Radiative Transfer) is a research model for simulating
the spectral and directional reflectance of dry and wet soils.

## Windows desktop edition

The desktop research preview includes SORT for directional dry and wet soil
reflectance, SORT-D for directional dry soil reflectance, and SORT-L for
Lambertian dry and wet soil reflectance. It supports single simulations,
one-parameter sensitivity analysis, batch simulations, and optical fitting
of observations. Macroscopic roughness options are experimental.

Windows downloads are listed under
[Releases](https://github.com/dinganxin/SORT-model-v1.0/releases).
Extract the entire ZIP, keep `_internal` beside `SORT.exe`, and open the
executable. The package includes Chinese and English user manuals and example
inputs. The full desktop source code is not distributed with this edition.

## Citation

When using the desktop software, report its build ID from **Help > About SORT**.
The following publications describe the model foundations:

1. Ding, A., Ma, H., Liang, S., and He, T. (2022). Extension of the Hapke model to the spectral domain to characterize soil physical properties. *Remote Sensing of Environment*, 269, 112843. [DOI](https://doi.org/10.1016/j.rse.2021.112843).
2. Ding, A., Ma, H., Liang, S., Jiao, Z., Kokhanovsky, A. A., Shi, H., and Xie, R. (2026). A unified Hapke-HSR + MARMIT-2 soil radiative transfer model for reflectance simulation under varying moisture conditions. *Geoscientific Model Development*, 19, 4775-4795. [DOI](https://doi.org/10.5194/gmd-19-4775-2026).
